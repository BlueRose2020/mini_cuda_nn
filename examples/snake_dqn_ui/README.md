# Snake DQN UI

此页面独立使用 JavaScript 训练，不调用 C++/CUDA 后端。训练核心与 Node 验证使用同一个 `dqn.js`。

## 启动

在本目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\serve.ps1 -Port 8090
```

打开终端实际打印的地址。更新后先 Ctrl+C 停止旧服务，再执行上述命令并在浏览器 Ctrl+F5。旧版本参数仅在内存中，不会迁移；重新训练即可。

## 控制与指标

- 开始训练：从当前参数和未结束的训练回合继续；调度按步数和时间切片，长回合不会堵住按钮。
- 暂停：取消当前调度。若中断独立评估，该次未完成评估不记录。
- 运行当前策略：冻结当前在线网络，在固定种子的新环境逐帧播放，不训练、不修改探索率、不消耗训练随机数。
- 播放最佳评估快照：播放截至目前独立评估平均得分最高的快照。不会偷偷回滚训练参数。
- 重置：清空参数、回放、Adam 状态、曲线和快照。刷新页面也会清空。
- 灰线为每局训练回报，蓝线为最近 50 局平均回报，黄线为每 100 回合执行一次的 10 局独立贪心评估回报。
- 得分为吃到的食物数；回报为吃食物 +1、碰撞 -1、普通移动 -0.01 的总和。单局回报允许为负。
- 最高分是历史单局纪录，不代表当前策略；应同时看评估平均得分、平均回报及 loss/Q 值。

## 本次修复

1. 每个批次以同一份参数计算全部梯度，除以批大小后只执行一次优化器更新。隐藏层梯度使用更新前的输出层权重。
2. Double DQN 使用在线网络选动作、目标网络估值；32 样本平均 Huber loss、Adam 学习率 0.0005、全局梯度范数上限 5。
3. 回放至少 256 条后开始学习，每 4 个环境步更新一次；目标网络每次优化器更新以 tau=0.005 平滑跟随，不再依赖回合长度。
4. 播放不会把训练 epsilon 改成 0。训练 epsilon 按已完成回合数衰减，下限 0.1。
5. 500 步游戏上限按终局存入回放；修复走进即将移开的尾巴被误判碰撞、填满棋盘时生成食物死循环。
6. 每次更新检查有限数值，发现异常停止并显示日志。未用截断回报或限制曲线范围掩盖退化。

11 维特征不包含完整蛇身布局，仍有观测局限；单局或评估窗口波动不等于实现错误，测试也不能保证无限训练始终不退化。

## 验证

```powershell
node .\test_dqn.cjs
node .\long_run.cjs 10000 42 7 123
```

`test_dqn.cjs`：全部参数的有限差分梯度、批次重复不放大更新、Double DQN 目标、终局不 bootstrap、尾巴/满盘/超时规则、播放不修改 epsilon、定时器取消和重置。

`validation.jsonl` 记录 2026-09-13 使用同一训练核心的三个种子各 10,000 回合结果；每 200 回合用固定种子评估 10 局：

| 训练种子 | 第 10,000 回合最近 100 局平均回报 | 最终评估平均得分 | 第 2,000 回合起检查点的最低 100 局平均回报 |
| --- | ---: | ---: | ---: |
| 42 | 7.85 | 21.4 | 6.41 |
| 7 | 7.68 | 20.3 | 6.82 |
| 123 | 7.57 | 24.1 | 6.38 |

这里的检查点均未出现后期持续负回报，记录的批次最大 |Q| 小于 3.23。还通过真实 Edge 页面验证开始、暂停、逐帧播放、恢复、独立评估和重置，无 JavaScript 异常。评估为固定种子的诊断，不是全环境泛化或最优策略证明。
